# Personal Portfolio

A modern and responsive personal portfolio website built with Next.js, showcasing my projects, technical skills, education, and UI/UX design work.

## About

I am a Computer Science student at Bina Nusantara University (BINUS) with hands-on experience in web development, Android application development, and UI/UX design through various academic and personal projects.

## Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Frontend:** React
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **UI/UX Design:** Figma
- **Tools:** Git, GitHub, VS Code, Android Studio

## Features

- Responsive design
- Modern and clean user interface
- Project showcase
- Skills and education section
- UI/UX design showcase
- Contact form

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Hendryann/personal-portfolio.git
```

Navigate to the project directory:

```bash
cd personal-portfolio
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the website.
